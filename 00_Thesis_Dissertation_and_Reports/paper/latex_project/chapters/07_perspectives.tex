\section{Perspectives}

Les prochaines étapes prévues sont :
\begin{itemize}
    \item Sélection et formalisation d’un cadre d’apprentissage incrémental adapté aux contraintes embarquées.
    \item Définition de scénarios HRC concrets (co-manipulation, navigation partagée, adaptation comportementale).
    \item Conception d’une architecture logicielle intégrant :
    \begin{itemize}
        \item perception multimodale,
        \item interaction humain–robot,
        \item mécanismes d’apprentissage progressif.
    \end{itemize}
    \item Implémentation et validation expérimentale sur la plateforme développée.
    \item Évaluation comparative sur datasets identifiés et scénarios réels.
\end{itemize}
